# What the Heart Keeps

A small story-sharing website made with HTML, CSS, and JavaScript.

## Files

- `index.html` — home page and stories
- `about.html` — about and contact page
- `login.html` — login and registration form demonstration
- `style.css` — shared visual styles
- `script.js` — story categories, reactions, navigation, and anonymous submissions

## Current demo limitations

Anonymous submissions are saved in the visitor's browser using local storage. They are not sent to a server and are not shared with other visitors. The login and registration forms are visual examples and do not create accounts.

To share submissions among visitors, connect a Python backend and a persistent database. To publish the static pages, enable GitHub Pages for this repository.
